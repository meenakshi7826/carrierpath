A practical weekly learning routine

Plan for 5 days a week, about 45–60 minutes a day (roughly 4–5 hours weekly). Durations are estimates; your pace may differ.

  1. Weeks 1–2: Learn the basics from one beginner playlist and write down key ideas.
  2. Weeks 3–4: Practise each concept yourself; pause the video and recreate the example without copying.
  3. Weeks 5–6: Build a small project that uses several things you learned; ask someone to try it.
  4. Weeks 7–8: Improve the project, write what you learned, and choose the next skill to practise.

Tip: spend about 20–30 minutes watching, then use the rest of the session to practise. Course and video lengths change; check the current playlists.

Learn AI & Machine Learning

Start with the ideas, build a strong foundation, and learn by making small projects.

A strong beginner path is to learn Python, data basics, simple ML, then explain and test your work every week.

AI & ML Personalised 12-Week Roadmap

Follow the plan below in order. Repeat a day if needed, but keep moving forward.

1️⃣

Week 1: Python and AI basics

Learn variables, loops, functions, lists, and conditionals. Start with small Python projects and basic problem-solving.

2️⃣

Week 2: Data and statistics

Work with spreadsheets, simple charts, averages, and probability. Understand missing values, patterns, and data quality.

3️⃣

Week 3: Data cleaning

Clean messy data, check common errors, and learn how to prepare a small dataset for analysis and model training.

4️⃣

Week 4: ML fundamentals

Learn the difference between inputs, labels, training, and testing. Study supervised learning, prediction, and classification.

5️⃣

Week 5: Models and metrics

Train a basic model, compare accuracy, evaluate results, and note where the model fails or needs more data.

6️⃣

Week 6: Evaluate and present

Measure error, choose a dataset, run training, and write a short project summary with findings and limitations.

7️⃣

Week 7: Feature engineering

Improve the input data by representing information more clearly. Test small changes and compare performance.

8️⃣

Week 8: Model tuning

Improve your model, review assumptions, and choose the model that best fits the task without overfitting.

9️⃣

Week 9: Neural networks

Understand neurons, weights, activation functions, and how a simple network turns inputs into outputs.

🔟

Week 10: Deep learning basics

Study layers, loss functions, optimization, and training cycles. Learn the basics without trying to build a huge model too early.

1️⃣1️⃣

Week 11: Generative AI fundamentals

Learn what generative AI is, how LLMs predict text, and how prompting works. Always verify the output and recognise its limitations.

1️⃣2️⃣

Week 12: Final AI project

Plan a study assistant or a simple AI prototype, test it carefully, improve safety, and present your results clearly.

Daily AI learning habits

Use these habits to make real progress and stay consistent.

Use the 3-2-1 method

Write 3 things you learned, 2 examples, and 1 question each day. This keeps learning active and practical.

Do not copy code blindly

Change the input, modify a condition, and predict the result. Coding is a thinking exercise, not a copy-paste activity.

Explain it in plain language

Teach the concept to yourself out loud or to a friend. If you can explain it simply, you understand it better.

Review and repeat

Repeat the next day and again a few days later. Small practice sessions are more effective than long, passive study.

What is AI?

Artificial intelligence (AI) is a broad field of making computer systems perform tasks that usually need human-like abilities, such as understanding language, recognizing images, or making recommendations.

📈

What is machine learning?

Machine learning (ML) is one way to build AI. A model learns patterns from examples and uses them to make predictions or decisions. Better data and careful testing matter.

🧩

Key AI ideas

Learn supervised learning (labelled examples), unsupervised learning (finding patterns), and reinforcement learning (learning through feedback). Deep learning uses multi-layer neural networks.

✨

Generative AI

Generative AI creates new text, images, audio, or code from patterns it learned. Its answers can sound convincing and still be incorrect, so check important facts.

Build your foundation

No special background is needed. Learn one step at a time and practise consistently.

1. Start with Python

Practise variables, conditions, loops, functions, lists, and dictionaries. Write short programs before moving on.

2. Get comfortable with data

Use tables, charts, averages, and basic probability. Learn to spot missing, biased, or unreliable data.

3. Try beginner ML

Explore a small classification or prediction example. Split data into training and test sets and compare the results.

4. Build and explain

Make a tiny project, document what it does, where its data came from, and what it gets wrong. Share only data you have permission to use.

Beginner learning tips

Small, repeatable habits beat trying to learn everything at once.

Learn actively

Pause lessons and recreate examples without copying. Change one thing and see what happens.

Keep a question notebook

Write down new terms, errors, and what you tried. Explain each idea in your own words.

Build tiny projects

Start with a simple study-time predictor or a hand-labelled image sorter. Make the goal small enough to finish.

Check AI answers

Use AI tools as helpers, not authorities. Verify facts, understand generated code, and protect personal information.
